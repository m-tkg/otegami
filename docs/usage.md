# 使い方ガイド

otegami の機能を、実際に使う流れに沿って説明する。UI 設計の背景や各改修
の経緯は [docs/design-system.md](design-system.md)、設定項目の全一覧は
[docs/settings.md](settings.md) を参照。

## アカウントの追加

ハンバーガーメニュー（iOS）またはサイドバー（macOS）の「アカウントを
追加」から、種類ごとの追加フォームに進む。

- **Gmail** — OAuth2 (`ASWebAuthenticationSession`) でブラウザ経由の
  サインイン。ビルド時に Client ID が設定されていないと無効化される
  （[docs/oauth-setup.md](oauth-setup.md)）。
- **iCloud** — メールアドレスとアプリ用パスワード（Apple ID のパスワード
  ではない）を入力する専用フォーム。
- **Yahoo!メール / Yahoo!メール(JAPAN)** — ホスト/ポート/セキュリティを
  事前入力した専用フォーム。Yahoo!メール(JAPAN) はメールアドレスとは別に
  編集可能な「ログイン ID」欄がある。
- **Outlook.com / Office365** — Microsoft OAuth2 でブラウザ経由の
  サインイン。同じく Client ID 未設定時は無効化される。
- **Exchange / その他 (IMAP)** — 汎用の IMAP/SMTP フォーム。Exchange は
  ホスト/ポート/セキュリティのプリセットが入った状態で開く。開発用
  メールスタックに接続する場合もこのフォームを使う
  （[docs/dev-mailstack.md](dev-mailstack.md)）。

追加したアカウントは同じ Apple ID の他デバイスにも自動的に現れる
（[docs/icloud-sync.md](icloud-sync.md)、設定でオプトアウト可能）。

## 一覧の操作

- **統合受信トレイと絞り込み**: 「すべて」チップで全アカウント横断、
  個別チップで1アカウントに絞り込み。ヘッダの「未読のみ表示」トグルで
  未読のみに絞れる。
- **アカウントダイジェスト**: ヘッダの「アカウントでグループ化」ボタン
  でダイジェスト画面に切り替わる。アカウントごとに1行（色罫線・表示名・
  未読/件数バッジ・直近2〜3件のプレビュー）が並び、行をタップすると
  そのアカウントの一覧に絞り込まれる。行をスワイプすると確認ダイアログ
  を挟んで一括処理（アーカイブ/削除/迷惑メール/既読切替/ピン留め）が
  できる。
- **スワイプ操作**: 左右それぞれの短い/長いスワイプに、既読/未読切替・
  アーカイブ・迷惑メールにする・ピン留め・削除を個別に割り当てられる
  （設定 →「メール一覧」）。削除・迷惑メールは常にタップ確定で誤操作を
  防ぐ。macOS はスワイプの代わりに行の右クリックメニューを使う。
- **長押し一括選択**: 一覧の行を長押しすると複数選択モードになり、下部
  のアクションバーからまとめて操作できる。
- **ピン留め**: メール/スレッドを一覧の最上位に固定する。既定はこの端末
  だけのローカルな印だが、設定で IMAP `\Flagged` と連動させ他クライアント
  とも同期できる。
- **並び替えなしの検索・プルツーリフレッシュ**: 一覧を下に引くと再同期
  する。

## メール本文の閲覧

- **スレッドのアコーディオン**: 2通以上のスレッドを開くと、全メッセージ
  が時系列に縦に並び、最新の1通だけが展開される。他のメッセージのヘッダ
  をタップすると、そちらが展開され元の展開は畳まれる。iOS・macOS 共通の
  挙動で、一覧側には複数メッセージのスレッドだとわかるアイコン付きの
  件数バッジが付く。
- **引用履歴の折りたたみ**: プレーンテキストの返信メールでは、引用され
  た過去のやり取りが1通ずつのカードに分解して表示される。「履歴を表示/
  非表示」で開閉できる（既定は表示、HTML メールは対象外）。
- **AI要約**: 「要約」ボタンをタップすると、■要約/■伝えたいこと/
  ■アクションの3パート構造の要約を生成する。返信メールでは引用された
  過去のやり取りを除外し、新しい本文だけを対象にする。生成後に「詳しく
  要約」を選ぶと、より詳細な要約に再生成できる。
- **翻訳**: 「翻訳」ボタンをタップしたときだけ翻訳が実行される（自動
  翻訳は既定オフ、設定でオンにしても確信度の高い英文メールにのみ発火）。
  訳文表示中はワンタップで原文に戻せる。プレーンテキストは段落を長押し
  すればその段落だけ原文を確認でき、HTML メールは表・画像・レイアウト
  を保ったまま本文の文字だけが翻訳される。
- **ソース表示**: フッターツールバーの「その他」から生の RFC822 ソース
  を表示・共有できる。表示が崩れるメールを調べるときに使う。
- **カレンダー招待**: 招待メールを開くとタイトル・日時・場所・主催者を
  示すカードが表示され、「承諾」「辞退」「未定」をタップすると主催者へ
  自動で回答が送られる（[docs/calendar-invites.md](calendar-invites.md)）。
- **フッターツールバー**: 返信/転送/検索（差出人で絞り込み）/情報/その他
  （ミュート・ピン留め・アーカイブ・迷惑メール・削除・要約・翻訳・
  ソース表示などを含む14アクション）。表示するアクションと並び順は設定
  →「メールビューア」からカスタマイズできる。
- **HTML メール**: サンドボックス化された `WKWebView` で描画（JavaScript
  無効）。「HTML」バッジからワンタップでプレーンテキスト表示に切替可能。
  埋め込み画像は既定オフ、リモート画像は既定オンで、メールごとに
  「画像を表示」バナーで一時的に上書きできる。

## 作成・返信・転送

- 送信元アカウントの選択は必須（誤送信防止）。
- テンプレート（本文の定型文、設定で管理）と署名テンプレート（アカウント
  ごとのデフォルト署名）を「テンプレートを挿入」/「署名」メニューから
  選べる。
- 添付ファイルは「添付」メニューからファイル・写真・（実機のみ）カメラ
  撮影を選択。転送では元メールの添付を引き継ぐ。
- iOS の送信は Outbox への即時保存＋設定可能な5秒/10秒/なしの猶予
  カウントダウン＋「送信を取り消す」ボタン。アプリを離れると即座に送信
  が確定する。
- 下書きは両プラットフォームでローカル保存され、IMAP 経由で双方向に
  同期される。

## 検索

ヘッダの検索ボタン（iOS は左下フローティング）から検索画面を開く。

- `from:`/`to:`/`cc:`/`subject:` の検索演算子とフリーテキストを組み合わ
  せられる。
- 2アカウント以上ある場合はアカウント絞り込みチップが使える。
- 「履歴」タブに直近の検索クエリ（タップで再検索、スワイプで削除）、
  「保存済み」タブに保存済み検索が並ぶ。

macOS は一覧画面自体の `.searchable` インライン検索を使う（演算子は
共通、履歴/保存済みタブの UI は iOS 専用）。

## 通知

- プッシュ通知は任意でセルフホストするリレーサーバー
  (`server/otegami-relay-go`) を設定すると受け取れる。設定 →「アカウントの
  設定」からオプトインする。件名/本文はワイヤーに乗らず、実際の内容は
  端末の Notification Service Extension が自分の IMAP 接続で取得する
  （[docs/relay-deployment.md](relay-deployment.md)）。
- 統合受信トレイの未読数をアプリアイコンにバッジ表示できる（設定で
  オン/オフ）。

## 設定

設定画面（iOS: ハンバーガーメニュー→「設定」、macOS: 標準の Settings
シーン）は次の4カテゴリ＋ルート直下の「このアプリについて」に整理され
ている。

| カテゴリ | 内容 |
|---|---|
| アカウントの設定 | アカウントの追加削除、デフォルトの送信アカウント、iCloud 同期、プッシュ通知 |
| メールビューア | リンクの開き方、削除/アーカイブ後の挙動、AI 機能 (翻訳・要約) の on/off、画像設定、HTML 表示設定、フッターツールバーのカスタマイズ |
| メール一覧 | プロフィール画像表示、プレビュー行数、スワイプ操作、スレッド表示、ピン留めの IMAP フラグ連動 |
| メール作成 | テンプレート、署名テンプレート、送信取り消しの猶予秒数 |

表示言語（日本語/English）はアプリ内には切替 UI が無く、iOS 標準の
「設定 → このアプリ → 言語」（アプリ単位言語設定）で切り替える。項目
ごとの詳細は [docs/settings.md](settings.md) を参照。
